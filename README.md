📘 EduSmart AI
🚀 Smart Educational PDF Analysis Platform

EduSmart AI is a web-based application built using Streamlit that allows users to upload PDF documents, extract text, summarize content, and analyze learning materials in an easy and interactive way.

It also stores usage data and can be connected to dashboards using Microsoft Power BI for educational analytics.

🎯 Features
📄 Upload and read PDF files
🧠 Summarize content automatically
📊 Store usage data (file name + word count)
📁 View uploaded file history
🌐 Web-based interface
📈 Ready for data visualization integration
🛠️ Tech Stack
Python
Streamlit
PyPDF2
Pandas
Power BI (for analytics)
⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/edusmart-ai.git

Go to project folder:

cd edusmart-ai

Install dependencies:

pip install -r requirements.txt

Run the app:

streamlit run app.py
📊 Data Analytics

The application generates a students.csv file containing:

File name
Word count

This data can be imported into Microsoft Power BI to create dashboards for:

Student activity tracking
Content usage analysis
Learning insights
